# Subtitles

> [!TIP]
> Sorry, currently only supports online downloading of Chinese subtitles. If you need to localize online subtitles, please add the corresponding plug-in extension by yourself.

## Subtitle size, color

- Can be set in the player
- Permanently valid settings
  Open the `mpv.conf` file for editing

```conf
# Font color
sub-color="#dadee3"
# font size
sub-font-size=36
```

- [mpv subtitles](https://mpv.io/manual/master/#subtitles)
