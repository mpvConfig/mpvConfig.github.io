# Common Keyboard Shortcuts

- `p` — Open Recent Playlists
- `Alt + f` — Search subtitles
- `Ctrl + d` — Search danmaku
- `d` — Show/hide danmaku
- `Alt + d` — Open the danmaku master toggle menu
- `O` — Show/hide OSD messages (top-right information, including playback time and system time)
- `Ctrl + t` — Keep the window on top
- `Ctrl + -` — Zoom out
- `Ctrl + +` — Zoom in
- `a` — Change video aspect ratio
- `e` — Open the visual equalizer adjustment panel
- `i` — Show statistics (file, decoding, shader/filter information, etc.)
- `l` — A-B loop playback (lowercase L)
- `m` — Mute
- `]` — Increase playback speed
- `[` — Decrease playback speed
- `Enter` — Enter/exit fullscreen
- `↑` — Increase volume
- `↓` — Decrease volume
- `→` — Seek forward
- `←` — Seek backward
- `<` — Previous frame
- `>` — Next frame
- `Mouse wheel button / Space` — Pause/play
- `Left mouse button` — Hold and drag in the middle of the video to move the window
- `Ctrl + i` — View and configure all shortcuts (mpv.net only)

## How to modify and add shortcut keys?

- The shortcut key setting file can be seen by opening and editing `portable_config/input.conf`. Just refer to the settings (ask AI if you don’t understand)
