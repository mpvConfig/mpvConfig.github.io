# How to Update to the Latest Version

- To check for updates in the player, right-click and select Tools > Check for updates.
- Player update: Simply download and install the latest [mpv player](https://mpv.io/installation/)
- Configuration/theme update: Simply [🎯 download the latest version](https://github.com/akFace/mpv.config/releases), extract it, and overwrite the existing files to configuration folder. (Back up your files before overwriting)

```
A typical directory structure looks like this:
~/mpv/portable_config
      ├── fonts
      ├── scripts
      ├── script-opts
      ├── mpv.conf
      └── input.conf
```
