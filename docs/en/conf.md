# UI Size & Appearance Settings

## Customize Your Interface

You can customize the appearance of the interface, including font sizes, colors, and various other styles.

> [!IMPORTANT]
>
> It is recommended to use these settings alongside the [Custom Configuration Guide](./custom.md), as some settings may be overwritten when switching theme color schemes.
>
> To make changes, open the relevant configuration files with a text editor or another editor of your choice.

- **uosc** — Theme customization guide: [uosc Options](https://github.com/tomasklaen/uosc#options)  
  File location: `script-opts/uosc.conf`

---

- **ModernZ** — Theme customization guide: [ModernZ Customization](https://github.com/Samillion/ModernZ#customization)  
  File location: `script-opts/modernz.conf`

---

- **ModernGlass** — Theme customization guide: [ModernGlass User Options](https://github.com/Demetter/ModernGlass/blob/main/docs/USER_OPTS.md)  
  File location: `script-opts/modernz.conf`

---

- **Menu Styles** — Customization guide: [mpv-menu-plugin-next](https://github.com/mpvConfig/mpv-menu-plugin-next/blob/main/doc/README.md#menu_styleconf-%E9%85%8D%E7%BD%AE%E8%AF%B4%E6%98%8E)  
  File location: `script-opts/menu_style.conf`
- [Custom Configuration](./custom.md)

---

- **Subtitles** — See the [subtitles](https://mpv.io/manual/master/#subtitles)

---

- **Danmaku** — The default style is configured in `script-opts/uosc_danmaku.conf` inside the configuration folder.
- Danmaku configuration guide: [View Documentation](https://github.com/Tony15246/uosc_danmaku#%E7%9B%AE%E5%BD%95)

## Set the Default Window Size on Startup

- In the player, go to **Right-click Menu > Window > Window Size**.

## Switch Theme Colors

- In the player, go to **Right-click Menu > Tools > Switch Theme > Select a Theme**.
