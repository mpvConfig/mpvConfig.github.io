# 常用快捷键

`Alt + f` — 搜索字幕  
`Ctrl+d` — 搜索弹幕  
`d` — 显示/隐藏弹幕  
`Alt+d` — 打开弹幕总开关菜单  
`O` — 显示/隐藏 OSD 界面消息（右上角信息：包括视频时间进度、系统时间）  
`Ctrl+t` — 置顶窗口  
`Ctrl+-` — 画面缩放：缩小  
`Ctrl++` — 画面缩放：放大  
`a` — 画面纵横比例  
`e` — 打开可视化调节均衡器面板  
`i` — 统计显示信息（文件、解码、滤镜信息等）  
`l` — A-B 循环播放（小写的 L）  
`m` — 静音  
`]` — 播放倍速+  
`[` — 播放倍速-  
`Enter` — 全屏/退出全屏  
`↑` — 音量+  
`↓` — 音量-  
`→` — 快进  
`←` — 快退  
`<` — 上一帧  
`>` — 下一帧  
`鼠标滚轮键/空格` — 暂停/播放  
`鼠标左键` — 在画面中间处按住拖动窗口  
`Ctrl + i` — 查看和设置所有快捷键 (仅 mpvnet 有效)

- 右键菜单也可查看功能对应的快捷键
