# 默认行为

mpv 启动时默认不启用视频增强滤镜、插帧，只有用户自主选择时才启用

```
mpv启动时默认：
      ┌──────────────┐
      │ 正常播放      │
      │ 无 Anime4K    │
      │ 无插帧        │
      │ 无 Shader 链  │
      └──────────────┘
               │
               │ 用户右键菜单选项主动选择
               ↓
      ┌───────────────────┐
      │ 视频增强           │
      ├───────────────────┤
      │ Anime4K HQ/Fast   │
      │ FSRCNNX           │
      │ ArtCNN            │
      │ CuNNy             │
      │ NNEDI3            │
      │ CFL               │
      │ FSR               │
      │ Sharpen           │
      └───────────────────┘
```

## 自动保存用户设置的数据（全局）

配置文件在`script-opts/celebi.conf`下，如需增加保存其他的`mpv.conf`配置设置项，请手动修改`celebi.conf`，保存的用户设置数据在`portable_config/celebi.txt` 要恢复默认状态，删除`celebi.txt`文件重启播放器即可

```
# ======下次启动会根据用户设置加载======
# ======以下参数会自动保存的设置名称======
# 音量
volume=yes
# 视频帧同步模式
video-sync=yes
# 自动加载icc配置文件
icc-profile-auto=yes
# 色彩调整
contrast=yes
# 亮度
brightness=yes
# 伽马
gamma=yes
# 饱和度
saturation=yes
# 色调
hue=yes
# 自动适应窗口大小
autofit=yes
# 界面消息字体大小
osd-font-size=yes
# 界面消息对齐方式
osd-align-x=yes
# osd 界面等级
osd-level=yes
```

## mpv 内置保存状态（单视频）

默认启用 `save-position-on-quit = yes` 主要保存的是**文件的播放进度**，同时也会连带保存**一部分在播放过程中被修改过的播放器状态**。

### 🎯 核心保存内容：播放进度

这个选项最根本的作用，是让 mpv 在退出时，自动保存当前文件的播放位置。当你下次打开**同一个文件**时，播放器会自动跳转到上次退出的地方继续播放。

它和手动按 `Shift+Q`（`quit-watch-later`）的区别在于，`save-position-on-quit` 是**无条件自动保存**的，即使你是通过点击窗口关闭按钮退出的，进度也会被记录。

### 📦 连带保存的播放状态

除了播放位置，mpv 还会将一些在播放开始后**被你修改过**的选项一并保存。根据官方文档和提交记录，这些状态可能包括：

- **音视频轨道选择**：你手动切换的音轨或字幕轨。
- **音量与静音状态**：调整过的音量或静音设置。
- **播放速度**：调整过的倍速。
- **字幕相关设置**：如字幕延迟、字幕位置、字幕可见性等。
- **画面调整**：如亮度、对比度、饱和度、色调等。

> **注意**：这些状态**只有在播放过程中被修改过**才会被保存。如果一直使用默认设置，它们不会被记录。
