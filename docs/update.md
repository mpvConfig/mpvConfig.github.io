# 如何更新到最新版

- 查看是否为最新版本，播放器内：右键 > 工具 > 检查更新
- 播放器更新：直接下载最新版 [mpv 播放器](https://mpv.io/installation/) 安装即可
- 配置主题皮肤更新：直接下载最新版[🎯 点击下载](https://github.com/akFace/mpv.config/releases) 解压覆盖到配置文件夹即可

```
配置文件夹路径，一般的目录结构如下:
~/mpv/portable_config
      ├── fonts
      ├── scripts
      ├── script-opts
      ├── mpv.conf
      └── input.conf
```

- 如何自定义配置 `mpv.conf` 与快捷键/菜单 `input.conf` 、`script-opts/` 目录中的任意`.conf`文件，在更新版本时直接覆盖不受影响？ 📢 [查看教程](https://akface.github.io/mpv.config/docs/custom)
